---
title: "Estimate Deposit Fees"
api: "POST /api/v1/fees/estimate/deposit"
description: "Preview the fees for a deposit before creating it."
---

Returns the full fee breakdown for a prospective deposit — application fee, estimated provider fees, the total the payer would pay, and the net amount credited — without moving any money. Show it to users before they confirm.

### Request Body

<ParamField body="amount" type="number" required>
  The deposit amount to estimate, in the application's base currency. Must be greater than 0.
</ParamField>

<ParamField body="payment_method" type="string" required>
  One of `mobile_money`, `card`, `bank`, or `wallet`.
</ParamField>

<ParamField body="is_international" type="boolean" default="false">
  For card deposits: estimate with the international card rate.
</ParamField>

### Response

<ResponseField name="transaction_type" type="string">
  The estimated transaction type.
</ResponseField>

<ResponseField name="payment_method" type="string">
  The payment method the estimate was computed for.
</ResponseField>

<ResponseField name="fee_enabled" type="boolean">
  Whether your application fee applies to this transaction type.
</ResponseField>

<ResponseField name="fee_breakdown" type="object">
  The line items: `transaction_amount`, `application_fee`, estimated provider fees, `total_fees`, `total_amount_to_pay`, and `net_amount`.
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable summary of the estimate.
</ResponseField>

```python Python
print(estimate["fee_breakdown"]["total_amount_to_pay"])
```
