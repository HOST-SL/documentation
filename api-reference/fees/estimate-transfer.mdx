---
title: "Estimate Transfer Fees"
api: "POST /api/v1/fees/estimate/transfer"
description: "Preview the fees for a wallet-to-wallet transfer before creating it."
---

Returns the full fee breakdown for a prospective transfer — application fee, estimated provider fees, the total the payer would pay, and the net amount credited — without moving any money. Show it to users before they confirm.

### Request Body

<ParamField body="amount" type="number" required>
  The transfer amount to estimate, in the application's base currency. Must be greater than 0.
</ParamField>

### Response

<ResponseField name="transaction_type" type="string">
  The estimated transaction type.
</ResponseField>

<ResponseField name="payment_method" type="string">
  The payment method the estimate was computed for.
</ResponseField>

<ResponseField name="fee_enabled" type="boolean">
  Whether your application fee applies to this transaction type.
</ResponseField>

<ResponseField name="fee_breakdown" type="object">
  The line items: `transaction_amount`, `application_fee`, estimated provider fees, `total_fees`, `total_amount_to_pay`, and `net_amount`.
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable summary of the estimate.
</ResponseField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://hpay-api.host-sl.com/api/v1/fees/estimate/transfer \
  --header 'api-key: YOUR_API_KEY' \
  --header 'secret-key: YOUR_SECRET_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "amount": 25
  }'
```

```python Python
from hostpay import HostPay

client = HostPay(api_key="YOUR_API_KEY", secret_key="YOUR_SECRET_KEY")

estimate = client.fees.estimate_transfer(amount=25)
print(estimate["fee_breakdown"]["total_fees"])
```

```typescript TypeScript
import { HostPay } from "@hostpay/sdk";

const client = new HostPay({ apiKey: "YOUR_API_KEY", secretKey: "YOUR_SECRET_KEY" });

const estimate = await client.fees.estimateTransfer({ amount: 25 });
console.log(estimate.fee_breakdown.total_fees);
```
